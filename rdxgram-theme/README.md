# RdxGram Theme Module — ماژول سبک RdxGram برای اینستاگرام

ماژول Xposed سبک و مستقل (Kotlin) برای اینستاگرام 451.0.0.53.80؛ فقط دو کار
می‌کند و هیچ کار دیگری نمی‌کند:

1. **فونت Inter** — جای فونت پیش‌فرض sans-serif اندروید. فونت Inter آزاد است
   (SIL OFL 1.1، از google/fonts — نزدیک‌ترین فونت آزاد به SF Pro اپل؛
   SF-Pro فونت اختصاصی اپل است و استفاده نشده).
   فایل: `app/src/main/assets/fonts/Inter-Variable.ttf` — 876,576 بایت،
   SHA-256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`
   (لایسنس: `app/src/main/assets/fonts/OFL.txt`).
   چون فونت متغیر (variable) است، وزن درخواستی واقعاً اعمال می‌شود:
   light=300، medium=500، bold=700، black=900. فقط خانواده sans-serif
   عوض می‌شود؛ serif و monospace و فونت خود اینستاگرام دست نمی‌خورند.
2. **نوار پایین شناور شیشه‌ای** — کپسول نیمه‌شفاف + گوشه گرد + پیل پشت تب
   فعال + مخفی‌کردن دیوایدر (پورت هوک GlassTabBarHook از فورک شیشه‌ای).
   **بلور واقعی ندارد** — فقط کپسول نیمه‌شفاف است. دلیل: گذاشتن RenderEffect
   روی خود نوار، آیکون‌های خود نوار را تار می‌کند نه پس‌زمینه پشتش را؛
   بلور واقعی پس‌زمینه به سطح بلور زیر نوار نیاز دارد که از هوک ویو در
   دسترس نیست.

## هوک‌ها (حداقل ممکن)

- `Activity.onResume` — جست‌وجوی نوار و گرم‌کردن فونت.
- `Typeface.create` (چهار سربار String/Typeface × int/int,boolean) و
  `Typeface.defaultFromStyle` — فقط برای sans-serif.
- تلاش best-effort برای عوض‌کردن فیلدهای استاتیک `Typeface.DEFAULT` و
  `DEFAULT_BOLD` و `SANS_SERIF` با رفلکشن (اگر سیستم جلویش را بگیرد،
  هوک‌های create هنوز کار می‌کنند).
- هیچ دستکاری بایت‌کد (Smali) روی اینستاگرام، هیچ DexKit، هیچ تغییر
  اسم پکیج. ورود فقط از راه legacy Xposed API
  (`assets/xposed_init` + `META-INF/xposed/init` + `module.prop` با
  minVersion=82) — همان مسیری که LSPatch برای ماژول‌ها استفاده می‌کند.
  ماژول در اینستاگرام رسمی (`com.instagram.android`) و در نسخه کنار
  آن (`com.rdx.gram`) هر دو کار می‌کند.
  عمداً ورودی مدرن libxposed اضافه نشده تا سطح کرش کم بماند؛ اگر تست
  گوشی نشان داد ماژول اصلاً لود نمی‌شود، اضافه‌کردن ورودی مدرن قدم
  بعدی است، نه هوک بیشتر.

## سوییچ خاموش/روشن

ماژول به‌صورت پیش‌فرض هر دو ویژگی را روشن دارد. خود APK ماژول قابل
نصب جداگانه است (آیکون «RdxGram Theme» در لانچر) و دو سوییچ دارد
(فونت / نوار) که از راه یک ContentProvider فقط‌خواندنی و exportشده
(`ir.rdx.gram.theme.settings`) به پروسه اینستاگرام می‌رسد. اگر این
برنامه نصب نباشد یا پرووایدر در دسترس نباشد، هر دو گزینه روشن
می‌مانند. بعد از تغییر سوییچ، اینستاگرام را کامل ببندید و دوباره باز
کنید. برگرداندن کامل = نصب نسخه پایه اینستاگرام (بدون ماژول).

## بیلد

بیلد فقط روی GitHub Actions (ورک‌فلوی `rdxgram-theme.yml` در ریپوی
`Hosin-rd-x/rdxgram-build`): `./gradlew :app:assembleDebug` و بعد
LSPatch 1.0 روی اینستاگرام 451.0.0.53.80. APK نهایی با testkey امضا
می‌شود؛ پکیج `com.instagram.android` عوض نمی‌شود.
